这顿饭，怎么算？

  1. 录入每项金额。可以手动填写，也可以上传小票。AI 识别结果需要你检查后导入。
  2. 确认每项参与人。点名字上的勾，选择谁参与消费。也可以用一句话描述，让 AI 提议修改。
  3. 填写优惠、费用和垫付。整单优惠与额外费用按原始消费份额分配。垫付总额等于账单总额时，显示结清建议。
  4. 检查并导出。展开每个人的明细，查看每项份额，再下载分账单或 CSV。

账单金额使用整数“分”计算；不足一分的尾差按固定顺序分配，因此每人份额加起来始终与整单金额一致。

“保存到本机”只保存账单文字和分配，不保存小票图片。请在共用设备上使用后清除草稿。
